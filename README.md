# THIÊN ĐÀNG ONLINE — HÀNH TRÌNH ĐỨC TIN

Bản chơi thử MVP dạng game trình duyệt 2D hoạt hình, hỗ trợ tiếng Việt và tiếng Anh.

## Chơi thử
Mở `index.html` trên trình duyệt hoặc triển khai bằng GitHub Pages theo hướng dẫn bên dưới.

## Điều khiển
- Máy tính: WASD hoặc phím mũi tên để di chuyển; nhấn **E** để tương tác; **Esc** để tạm dừng.
- Điện thoại: dùng cụm phím điều hướng trên màn hình và nút **TƯƠNG TÁC**.
- Đến gần nhà thờ, Giuse, Maria hoặc vườn hoa để tương tác.

## Nội dung MVP
- Bản đồ làng 2D, nhà thờ, quảng trường, nhà dân, cây cối và vườn hoa.
- Nhân vật di chuyển, va chạm với công trình/cây cối.
- Ba nhiệm vụ: thăm nhà thờ, trả lời câu hỏi Kinh Thánh, giúp Maria hái hoa.
- Điểm Hành Trình, cấp hành trình và lưu tiến trình bằng localStorage.
- Chuyển đổi giao diện tiếng Việt / English.

## Xuất bản bằng GitHub Pages
1. Mở **Settings → Pages** trong repository.
2. Ở **Build and deployment**, chọn **GitHub Actions**.
3. Workflow `Deploy static game to GitHub Pages` sẽ tự chạy khi có commit lên nhánh `main`.
4. Sau khi Actions báo thành công, trang game có địa chỉ:
   `https://stylechic1987-boop.github.io/thien-dang-online-mvp/`

## Giới hạn hiện tại
Đây là demo một người chơi; tiến trình chỉ lưu trên trình duyệt/thiết bị hiện tại. Chưa có tài khoản, máy chủ, chat hay multiplayer realtime. Không mô phỏng bí tích và điểm trò chơi không đại diện cho ân sủng hay địa vị tôn giáo.
